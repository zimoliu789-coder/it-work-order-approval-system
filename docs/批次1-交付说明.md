## 一、修了什么

### 第 8 项 · 新建申请向导缺 12 种字段类型

**现象**：向导的「添加字段」里只有 4 种（单行文本 / 日期 / 数字 / 下拉选择），而编辑配置页（完整设计器）有 16 种。

**根因（比最初判断更准确）**：不是「两份数组写歪了」，而是
`ApplyFieldEditor.vue` **自己维护了一份写死的类型清单**：

```ts
// 旧代码
const SUPPORTED_TYPES: FormFieldTypeCode[] = ['TEXT', 'DATE', 'NUMBER', 'SELECT']
```

而向导用的正是这个组件、设计器用的是另一个组件 —— 于是同一个表单在两个页面能配的类型不一样。

**修法**：

| 文件 | 改动 |
| --- | --- |
| `types/form.ts` | 新增 **`addableFieldGroups()`** —— 由 `FIELD_TYPE_META` + `FIELD_CATEGORIES` 推导的「添加字段」清单，**全站唯一一份** |
| `components/ApplyFieldEditor.vue` | 删掉写死的 4 种类型清单，改用 `addableFieldGroups()`；菜单**按 4 个分类分组**展示全部 16 种 |
| `components/FormDesigner.vue` | **删掉它自己那份 `FIELD_TYPES_BY_CATEGORY` 数组**，同样改用 `addableFieldGroups()` |

⇒ 从此**加字段类型只需改元数据表**，两个编辑器不可能再不同步（需求里「共用同一套常量配置」已落实）。

### 第 5 项 · 下拉选项输入中文顿号不生效

**现象**：输入「事假、病假」，顿号不生效、拆不出第二个选项。

**根因（与最初描述不同，这点很关键）**：代码**本来就支持顿号** ——

```ts
// 旧代码：正则里明明有顿号
.split(/[、,，]/)
```

真正的病是**「受控回写 + 归一化」这个组合**：输入框绑的是 `:model-value="optionsText(field)"`
（`join('、')` 且**过滤空项**），而每次按键都解析回写。于是你打下「事假、」时，
**末尾那个顿号被当成空项丢掉、回写后变回「事假」** —— 分隔符在打字过程中被吃掉，
第二项永远输不进去。**顿号、半角逗号、全角逗号全都一样**，所以「只识别英文逗号」的直觉是错的。

> 结论：**照原描述去「加顿号兼容」是修不好的** —— 必须改数据结构。

**修法**：改成**标签式输入**（按用户 D1 选定的方案 B）

- `optionDrafts`（以**字段 key** 为键，不是下标）持有「正在输入的原文」，**不参与回写**；
- 敲下 `、` / `,` / `，` ⇒ **立即生成标签**，只把最后一段留在输入框；
- **回车** 提交残留文本；**失焦** 提交（粘贴后不按回车也能落库）；
- **输入框为空时退格** ⇒ 删掉最后一个标签；
- 空项忽略、**重复项自动去重**；
- 标签容器与输入框共用一个外框，聚焦时整体高亮（不是"框里套框"）。

### 顺带修掉的一个同类隐患

预检逻辑原本写死 `field.type === 'SELECT'` 才检查「有没有配选项」——
现在类型补齐了，**多选下拉 / 单选框 / 复选框**也带选项，写死 SELECT 会让它们**没有选项也照样能提交**。
已改为按元数据的 `supportsOptions` 判定 ✅（有回归用例钉住）。

## 三、五轴评审

| 轴 | 结论 |
| --- | --- |
| **功能** | 向导与配置页的字段类型**完全一致（16 种）**；选项可正常录入多个，分隔符不再被吃；预检覆盖全部带选项类型 |
| **接口** | **零接口变更**（纯前端）。`addableFieldGroups()` 是新增的前端导出函数，无外部消费方 |
| **数据** | **零迁移、零库变更**。选项落库格式不变（仍是 `{value,label}[]`，value 用文字），历史表单数据完全兼容 |
| **体验** | 菜单按 4 类分组（16 项平铺要扫一遍）；标签式输入有明确的即时反馈；退格删标签符合通用手感；粘一长串也能一次成型 |
| **边界** | 空项忽略 / 重复去重 / 只输草稿不回车算"已配"（避免自相矛盾报错）/ 字段上移下移时草稿按 key 跟随不串味 |

## 四、验收路径（Windows / 浏览器）

1. 前端 `npm run dev`，用超管登录 → **系统设置 → 申请类型与流程** → 「新建申请」向导；
2. 第二步「加表单字段」→ 点「**添加字段**」：
   - 菜单应列出 **16 项**，分 4 组（基础字段 / 选择字段 / 高级字段 / 布局元素）；
   - 找得到「**多行文本**」「附件上传」「人员选择」「部门选择」等此前缺失的类型；
3. 选「**单选下拉**」→ 在「选项」里输入 `事假、病假、年假`：
   - 敲顿号时**前面那段立刻变成标签**，输入框清空；
   - 回车 / 点别处后，最后一段也变成标签；
   - 重复输入同一项不会产生第二个标签；
   - 输入框为空时按退格可删掉最后一个标签；
4. 保存后进入**编辑配置页**，字段类型与向导里选的**一致**（不再出现"向导建不出来、编辑页才有"）；
5. 打开**完整表单设计器**（配置面板里的「打开完整流程设计器」旁的表单设计器入口）→ 字段库同样列出 **16 项**（两侧同源）。
